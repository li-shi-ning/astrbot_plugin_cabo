# CABO 卡牌

AstrBot QQ 官方群聊 CABO 卡牌插件，参考经典 CABO / Cambio / Golf 玩法实现。

## 调研结论

CABO 是一款以记忆和换牌为核心的卡牌游戏。每名玩家一开始有 4 张暗牌，目标是让自己 4 张牌的总点数尽量低。玩家可以抽牌堆、拿弃牌堆，或直接喊 `CABO`。喊出 CABO 后，其他玩家各获得最后一回合，随后摊牌，点数最低者获胜。

本插件采用常见 52 张牌规则：

- 每人 4 张暗牌。
- 开局自动知道第 1、2 张牌。
- `A=1`，`2-10` 按面值，`J=11`，`Q=12`。
- `K♦=0`，其他 `K=13`。
- `7/8`：看自己一张牌。
- `9/10`：看别人一张牌。
- `J/Q`：交换任意两张桌上牌。
- 抽牌后可以声明 2-4 张同点数牌进行配对：配对成功后这组牌被弃掉，抽到的牌留在手中，手牌数量减少。配对失败会展示并放回所选牌，抽到的牌弃掉，并失去本回合。

## 命令

| 命令 | 说明 |
| --- | --- |
| `CABO菜单` / `CABO帮助` | 查看规则和帮助 |
| `CABO创建` | 创建房间 |
| `CABO加入` | 加入房间 |
| `CABO退出` | 开局前退出 |
| `CABO开始` | 房主或管理员发牌开始 |
| `CABO看` / `CABO状态` | 查看公开状态 |
| `CABO我的牌` | 查看自己已知的牌 |
| `抽牌` | 从牌堆抽一张 |
| `拿弃牌` | 拿弃牌堆顶牌 |
| `换 1` | 用抽到的牌替换自己第 1 张 |
| `配对 1 2` / `配对 1 2 3` | 用抽到的牌替换一组同点数牌 |
| `弃牌` | 弃掉刚抽到的牌 |
| `看自己 1` | 使用 7/8 技能看自己第 1 张 |
| `看别人 2 3` | 使用 9/10 技能看 2 号玩家第 3 张 |
| `交换 1 1 2 2` | 使用 J/Q 技能交换 1 号玩家第 1 张和 2 号玩家第 2 张 |
| `CABO叫牌` | 喊 CABO 进入最后一回合 |
| `CABO结束` | 房主或管理员结束房间 |

## 按钮

- 所有游戏消息附带每名玩家自己的“我的牌”按钮，只显示自己已知的牌。
- 当前玩家会看到“抽牌”“拿弃牌”“CABO”按钮。
- 抽牌后会显示“换1”到“换4”“弃牌”和对应技能按钮。
- 所有按钮都不使用占位符，点击后插入对应命令。

## 当前实现

- 单局房间流程：创建 -> 加入 -> 开始 -> 回合 -> CABO -> 摊牌结算。
- 隐藏牌使用 QQ 官方 `only_for` 按钮，不发送私聊。
- 支持 2-5 人，默认最多 4 人。
